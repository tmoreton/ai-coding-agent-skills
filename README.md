# AI Coding Agent Skills

Curated engineering skills for the Coding Agents mobile app.

The app reads `registry.json` from this repository. Add a new skill by creating
`skills/<skill-id>/SKILL.md` and adding it to the registry.

Skill folders follow the Agent Skills shape: a required `SKILL.md` with `name`
and `description` frontmatter, plus optional `agents/openai.yaml` UI metadata.
